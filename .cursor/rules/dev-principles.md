# Development Principles (pstack-inspired)

- **Go deep first**: Understand before implementing. Read existing code patterns.
- **Less but higher quality**: Minimize LOC, maximize clarity and correctness.
- **Testable**: Write code that's easy to verify.
- **Agentic by design**: Tools are first-class - game functionality exposed as tools for the helper agent.
- **Simple stack**: HTML/JS, Laravel, Postgres. No overengineering.
- **Docker-first**: Everything runs via `dev.sh` and docker-compose.

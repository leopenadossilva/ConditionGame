# ConditionGame — Claude entry point

Read `AGENTS.md` first. It is the single source of truth for how this repository works:
non-negotiables, commands, the delivery loop, and guardrails.

Then read, as needed:

- `docs/spec/GAME_VISION.md` — what the game is
- `docs/spec/MVP.md` — current scope and acceptance criteria
- `docs/AGENTIC_DESIGN.md` — how Sage and the tool layer work
- `docs/WORKFLOW.md` — discovery, specs, and review for non-technical owners
- `.claude/skills/` — reusable procedures (discovery, feature slice, game design, UI craft, verification)

Do not install extra agent tooling unless the owner asks for it.
